# online-bookstore-sql-data-analysis
# Online Bookstore Data Analysis Using SQL

This project is an SQL-based data analysis project focused on an Online Bookstore. It uses PostgreSQL to manage and analyze data from three CSV datasets: Books, Customers, and Orders.

The project explores book information, customer details, and order transactions to generate meaningful business insights.

### Datasets
- **Books:** Book titles, authors, genres, publication years, prices, and stock.
- **Customers:** Customer names, email addresses, phone numbers, cities, and countries.
- **Orders:** Customer orders, book IDs, order dates, quantities, and total amounts.

### SQL Concepts Used
- Database and Table Creation
- Data Import Using CSV Files
- SELECT, WHERE, ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- GROUP BY and HAVING
- DISTINCT and LIMIT
- INNER JOIN and LEFT JOIN
- Subqueries and COALESCE

### Business Analysis
- Identifying the most expensive books.
- Calculating total bookstore revenue.
- Finding the most frequently ordered books.
- Analyzing customer purchasing behaviour.
- Identifying top-spending customers.
- Calculating books sold by each author and genre.
- Analyzing remaining book stock.

### Tools Used
- PostgreSQL
- pgAdmin 4
- CSV Files

### Objective
To develop practical SQL and data analysis skills by working with a real-world business scenario and extracting useful insights to support business decision-making.
